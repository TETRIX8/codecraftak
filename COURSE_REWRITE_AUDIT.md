# Аудит переработки курса

## Цель
Каждое из 24 занятий курса HTML → CSS → JavaScript должно открываться отдельным маршрутом и быть самостоятельным учебным материалом.

## Выполнено

Содержание каждого занятия расширено блоками «Разбор по шагам», «Частая ошибка» и «Проверка себя». К существующему объяснению и примеру добавлена понятная методика изучения и контроль результата.

Страница отдельного занятия содержит заголовок, этап и длительность, аналогию, учебный текст, кодовые примеры, практику, отметку завершения, список занятий и переход к следующему занятию.

## Мобильные требования

На ширине 320–375 пикселей контент должен занимать не больше ширины viewport. Основные правила: `min-w-0` для grid-колонок, `max-w-full` для статьи и кода, `overflow-x-clip` для страницы, перенос длинных заголовков, компактные внутренние отступы и уменьшенный шрифт кодовых блоков. Таблицы и код должны прокручиваться внутри собственного блока, а не расширять всю страницу.

## Проверки

TypeScript, ESLint изменённых файлов и production build проходят успешно. В сборке остаётся только существующее предупреждение о размере общего JavaScript-бандла и устаревшей базе Browserslist; это не блокирует публикацию.
