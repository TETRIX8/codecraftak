# Структура источника: Дорожная карта по изучению JavaScript

Источник: прикреплённый пользователем файл `Дорожная_карта_по_изучению_JavaScript_1.pdf`, 5 страниц.

Карта включает следующие направления:

1. Углублённые структуры данных: массивы, создание и индексы; push, pop, shift, unshift, splice, slice, concat, indexOf, forEach, map, filter, reduce, find, some, every, sort; циклы for, for...of, forEach; объекты, доступ через точку и квадратные скобки; Object.keys, Object.values, Object.entries, hasOwnProperty; деструктуризация.
2. Современный JavaScript ES6+: let/const и блочная область видимости; стрелочные функции и особенности this; шаблонные строки; деструктуризация; spread/rest; Promises; async/await; ES Modules.
3. DOM: getElementById, querySelector, querySelectorAll, getElementsByClassName, getElementsByTagName; textContent, innerHTML; атрибуты; style; createElement, appendChild, removeChild, remove.
4. События: addEventListener; click, mouseover, keydown, submit, load, scroll; объект Event, target, preventDefault, stopPropagation.
5. Асинхронность: callbacks, Promises, async/await, Fetch API и XMLHttpRequest.
6. Ошибки: try/catch, catch для промисов, try/catch с async/await.
7. Организация кода: ES Modules import/export и CommonJS require/module.exports.
8. Инструменты: Node.js, npm/yarn, bundlers Webpack/Vite/Parcel, ESLint.
9. Опциональный следующий шаг: React, Vue, Angular; компоненты, состояние, props.
10. Практика: калькулятор, To-Do List, «Угадай число», приложение с открытым API, клонирование интерфейса.

В проект добавлен курс на основе карты: `javascript-roadmap`, 16 отдельных страниц, 32 часа. Каждая страница содержит цель, аналогию, объяснение, пример кода, частые ошибки, проверку себя и практику.
