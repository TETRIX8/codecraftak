# Аудит игрового раздела

## Доступность
Репозиторий `TETRIX8/codecraftak` доступен публично, ветка `main` клонируется без авторизации. Проект — Vite/React/TypeScript с Supabase.

## Найденные проблемы

1. В клиентской функции `makeMove` отсутствует строгая проверка участника и `current_turn`, поэтому пользователь может отправить ход не в свою очередь.
2. Для крестиков-ноликов нет проверки диапазона позиции и наличия символа игрока перед записью.
3. В RPS можно повторно отправить выбор, а выбор не валидируется по белому списку.
4. В морском бою нет серверной/клиентской проверки корректности расстановки кораблей, повторного выстрела и диапазона клетки; победа считается по количеству попаданий без защиты от повторов.
5. При завершении игры награда берёт размер ставки из потенциально устаревшего `currentGame`, а не из строки игры, что может привести к неверному начислению.
6. При присоединении переданный `gameBetAmount` используется для проверки баланса, но фактическое списание идёт по `game.bet_amount`.
7. Отмена ожидания игры вручную обновляет баланс напрямую вместо атомарной RPC-функции возврата ставки.
8. В интерфейсе отсутствует таймер/защита от повторной отправки для отдельных действий; realtime обновления не заменяют серверную валидацию.
9. В миграции уже присутствует `quiz`, но клиент его не реализует; игровой каталог и схема расходятся.
10. В проекте есть блокирующая локальная проблема установки: pnpm останавливается на ignored build scripts; локальные `tsc` и ESLint доступны, но общий ESLint содержит многочисленные legacy-ошибки вне игр.

## План исправлений

Сначала усиливается единая проверка ходов в клиенте и SQL-ограничения обновления игр, затем исправляются расчёты ставок/возвратов, после чего добавляется новая игра Connect Four с тем же жизненным циклом матчей и проверками. Далее выполняются сборка, линт и ручная smoke-проверка маршрута `/games`.
